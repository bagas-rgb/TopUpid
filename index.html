Instruksi Pembayaran

Langkah-langkah pembelian:

  1. Isi ID Player dan Server dengan benar
  2. Pilih metode pembayaran yang diinginkan
  3. Isi email dan nomor telepon untuk notifikasi
  4. Klik "Konfirmasi Pembelian"
  5. Lakukan pembayaran sesuai instruksi yang diberikan
  6. Tunggu proses verifikasi (maksimal 15 menit)
  7. Diamond/UC/Coins akan langsung masuk ke akun game Anda

Catatan:

  • Proses top up 24 jam
  • Pastikan ID Player dan Server sudah benar
  • Pembayaran harus dilakukan dalam waktu 1 jam
  • Hubungi admin jika ada kendala
